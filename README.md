# 🐊 GredDro Bot

ربات تلگرامی برای مدیریت حساب کاربری، سیستم زیرمجموعه‌گیری (رفرال) و برداشت ارز دیجیتال (BNB / شبکه BEP20)، با پنل مدیریت کامل و عضویت اجباری چندکاناله.

ساخته‌شده با [python-telegram-bot](https://github.com/python-telegram-bot/python-telegram-bot) نسخه‌ی ۲۲.۷ به بالا (برای پشتیبانی از دکمه‌های رنگی و ایموجی‌های پریمیوم).

---

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 👤 حساب کاربری | نمایش آیدی، موجودی، تعداد زیرمجموعه، حداقل برداشت و لینک اختصاصی دعوت |
| 💰 برداشت | اعتبارسنجی موجودی، دریافت آدرس ولت (BEP20)، ثبت خودکار درخواست در کانال تایید |

| ❗️ راهنما | آموزش گام‌به‌گام گرفتن آدرس ولت از Trust Wallet |
| 🔒 عضویت اجباری | چندکاناله، مدیریت‌شده از پنل ادمین، بدون امکان ثبت تکراری |
| 🛠 پنل مدیریت | پیام همگانی، آمار کاربران، افزودن/حذف کانال عضویت اجباری |
| 🎨 دکمه‌های رنگی | استفاده از قابلیت جدید Bot API برای دکمه‌های آبی/سبز/قرمز |
| 💎 ایموجی پریمیوم | در تمام پیام‌های کلیدی ربات |

## 🚀 راه‌اندازی سریع

### ۱. نصب وابستگی‌ها
```bash
pip install -r requirements.txt --upgrade
```
> نیازمند پایتون ۳.10 یا بالاتر.

### ۲. تنظیمات
تمام مقادیر قابل‌تغییر داخل `config.py` هستن. سه‌تای اول (`BOT_TOKEN`, `BOT_USERNAME`, `ADMIN_IDS`) هم می‌تونن مستقیم داخل کد ست بشن، هم از طریق متغیرهای محیطی (مثلاً در Railway):

| متغیر | نوع | توضیح |
|---|---|---|
| `BOT_TOKEN` | env / کد | توکن ربات از [@BotFather](https://t.me/BotFather) |
| `BOT_USERNAME` | env / کد | یوزرنیم ربات بدون `@` |
| `ADMIN_IDS` | env / کد | آیدی عددی ادمین(ها)، با کاما جدا (`111,222`) |
| `WITHDRAW_CHANNEL` | کد | کانالی که درخواست‌های برداشت توش پست می‌شه |
| `STARTING_BALANCE` | کد | موجودی اولیه‌ی هر کاربر جدید |
| `MIN_WITHDRAW` | کد | حداقل مبلغ قابل برداشت |
| `REFERRAL_REWARD` | کد | پاداش هر زیرمجموعه |
| `CURRENCY_SYMBOL` | کد | نماد نمایش مبلغ (پیش‌فرض `$`) |

### ۳. اجرا
```bash
python bot.py
```
دیدن پیام `ربات روشن شد...` یعنی همه‌چیز درسته.

## ⚙️ چک‌لیست قبل از استفاده‌ی واقعی

- [ ] ربات رو **ادمین** کانال `WITHDRAW_CHANNEL` کن (برای پست درخواست‌های برداشت)
- [ ] هر کانالی که برای عضویت اجباری اضافه می‌کنی، ربات باید **ادمین** اون هم باشه
- [ ] کانال‌های عضویت اجباری از داخل خودِ ربات (`/admin` ← افزودن کانال) اضافه می‌شن، نه از کد
- [ ] از فایل `bot.db` مرتب بکاپ بگیر — موجودی و تاریخچه‌ی همه‌ی کاربرا اونجاست

## 🛠 پنل مدیریت

با دستور `/admin` باز می‌شه (فقط برای آیدی‌های داخل `ADMIN_IDS`؛ برای بقیه هیچ واکنشی نشون نمی‌ده):

- **📨 ارسال پیام همگانی** — به همه‌ی کاربرهای ثبت‌شده پیام می‌فرسته
- **📊 آمار کاربران** — تعداد کل کاربرها + ۳ نفر برتر از نظر تعداد زیرمجموعه
- **➕ افزودن کانال عضویت اجباری** — با اعتبارسنجی واقعی (چک می‌کنه کانال وجود داره و قابل‌دسترسیه) و جلوگیری قطعی از ثبت تکراری
- **➖ حذف کانال عضویت اجباری** — لیست کانال‌های فعلی رو نشون می‌ده، انتخاب کن تا حذف بشه
- **🔙 بازگشت**

## 🔐 نکات امنیتی

- **توکن ربات را هرگز در مخزن عمومی (public) قرار ندهید.** اگر این ریپو را روی گیت‌هاب می‌گذارید، حتماً **Private** باشد یا از متغیرهای محیطی (Environment Variables) به‌جای مقداردهی مستقیم در `config.py` استفاده کنید.
- اگر گمان می‌کنید توکن درز کرده، فوراً از طریق BotFather با دستور `/revoke` توکن جدید بگیرید.
- پرداخت واقعی ارز (ارسال BNB) **دستی** است — ربات فقط درخواست را ثبت و نمایش می‌دهد؛ تأیید نهایی و ارسال واقعی وجه بر عهده‌ی ادمین است.

---

## 🧱 پایداری در برابر خطا

- تمام خطاهای پیش‌بینی‌نشده توسط یک هندلر سراسری (`global_error_handler`) گرفته می‌شوند و فقط لاگ می‌شوند — یک خطا در پردازش یک پیام باعث از‌کارافتادن کل ربات نمی‌شود.
- کانال‌های عضویت اجباری با محدودیت `UNIQUE` در دیتابیس ذخیره می‌شوند؛ امکان ثبت تکراری فنی وجود ندارد.
- آدرس ولت با الگوی دقیق `0x` + ۴۰ کاراکتر هگزادسیمال اعتبارسنجی می‌شود.
- هر کاربر در هر لحظه حداکثر یک درخواست برداشت «در حال بررسی» می‌تواند داشته باشد.
